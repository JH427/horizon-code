Horizon Code × Laya
Integration explainer · October 2026
A local policy layer, not another agent

Give Qwen a gearbox.

Laya can make fast, typed decisions before Qwen runs. The useful job is not writing code—it is deciding when full deliberation is worth paying for. Qwen remains the coding engine; deterministic code remains the safety system.

Recommended first move

Shadow a thinking-budget router.

Ask Laya once per turn: fast path, deliberate path, or uncertain. Record the answer without changing behavior, then prove it beats both the current baseline and a simple rule.

Small, reversible, measurable

The shape

Keep Laya in a local sidecar. It supplies a probabilistic hint; Horizon Code decides whether that hint is safe to apply.

Laya sidecar

~421M

Receives a compact state and returns one closed choice with probabilities.

  • Loopback-only HTTP
  • CPU or ONNX first
  • Timeout means “use baseline”
→policy hint

Horizon Code policy

authority

Applies only approved, confidence-gated reductions in compute. It never expands permissions.

  • Off / shadow / active modes
  • Fail open to current behavior
  • Record every decision
→request options

coder

Still reasons, calls tools, edits files, repairs failures, and reports the result.

  • Existing capability boundary

Where performance can come from

Laya adds latency. It only wins if its choice avoids more Qwen work than the decision itself costs.
01 · START HERE

Thinking-mode routing

Use no-thinking or lower effort for obvious inspection, status, summary, and exact mechanical work. Revert to normal after failure, mutation, or ambiguity.

Best prize / cleanest A-B
02 · LATER

Tool-profile routing

Send a smaller schema bundle—inspect, edit, execute, or full—to reduce prompt processing and possible tool confusion. Always retry with the full allowed set.

Useful, but easier to get wrong
03 · FUTURE

Model routing

If Horizon later serves a fast small coder beside Qwen3.8, Laya can choose which model gets the turn. That is a larger potential win, but there is no second lane today.

The authority line

Decision models are schema-safe, not truth-safe. Confidence is evidence to measure—not permission to trust.

Laya may recommend

  • ✓Fast, deliberate, or uncertain inference mode
  • ✓A bounded tool-profile candidate
  • ✓Inspect, implement, verify, or recovery phase
  • ✓Escalation back to the full baseline

Laya must never control

  • ×Capability, shell, network, or destructive authority
  • ×Verification requirements or “task complete” gates
  • ×Tool arguments, paths, or command safety
  • ×Context protocol integrity or process cleanup

A bounded pilot

Zero-shot Laya is not the product. The product would be a Horizon Code-specific, calibrated policy head—if the evidence justifies one.
Build order

Run shadow modeAsk once per turn; log choice, probabilities, truncation, checkpoint, and cold/warm latency. Change nothing.
Challenge it with a dumb ruleIf Laya cannot beat a transparent read-only/otherwise-normal heuristic, stop. Neural bureaucracy is still bureaucracy.
Activate only selective winsHigh-confidence fast-path decisions only. Timeout, error, low confidence, mutation, or repair restores today’s Qwen settings.
Specialize only after evidenceTrain and recalibrate on compact Horizon Code decisions, with genuinely held-out evaluation data.
